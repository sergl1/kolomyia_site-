# Коломия — місто, яке варто відкрити

Навчальний концепт адаптивного туристичного вебсайту про Коломию.

## Як відкрити сайт

Відкрийте `index.html` у будь-якому сучасному браузері. Для перегляду не потрібні додаткові програми чи збірка.

## Що є в першій версії

- адаптивна українськомовна головна сторінка;
- поєднання живих фотографій із авторською CSS/SVG-ілюстрацією та ледь помітною фоновою текстурою;
- маршрут із чотирма культурними зупинками, довший блок про спадщину та практичні поради перед поїздкою;
- мобільне меню, плавне прокручування, поява блоків під час прокручування, делікатні ефекти наведення та підтримка `prefers-reduced-motion`;
- окрему сторінку з джерелами й фотокредитами: `sources.html`.
- примітка перевіряти актуальні графіки музеїв перед поїздкою.
